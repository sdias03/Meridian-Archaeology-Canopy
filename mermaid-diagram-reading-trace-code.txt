sequenceDiagram
    autonumber
    participant Station as Field Station
    participant Ingest as Telemetry Ingest<br/>(mrd_ingest / C)
    participant Store as SQLite DB<br/>(meridian.db)
    participant Orch as Orchestrator<br/>(orchestrator.py / Python)
    participant Model as Crop Growth Model<br/>(cropmod / FORTRAN)
    participant Parser as Output Parser<br/>(parse.py / Python)
    participant API as Services API<br/>(ApiServer / Java)
    participant Console as Operator Console<br/>(dashboard / JS)

    %% 1. Telemetry creation and Ingest
    Station->>Ingest: Transmit telemetry reading<br/>[Data: 44-byte binary frame, big-endian]
    Note over Ingest: Validates CRC-16 checksum<br/>Decodes fixed-point ints to engineering floats<br/>Applies QC range checks

    %% 2. Raw storage
    Ingest->>Store: INSERT OR REPLACE INTO reading<br/>[Data: SQL text piped to sqlite3 via popen]

    %% 3. Orchestration query
    Orch->>Store: Query weather readings for station and year<br/>[Data: SQL SELECT query]
    Store-->>Orch: Return readings<br/>[Data: SQLite rows to Python Reading objects]

    %% 4. Deck generation & Fortran run
    Note over Orch: Writes MERIDIAN.DAT in scratch directory<br/>Combines readings with soil and latitude
    Orch->>Model: Execute cropmod subprocess<br/>[Data: Fixed-width ASCII deck (FORMAT 900/901/902)]

    %% 5. Fortran computation
    Note over Model: Computes daily soil-water and crop growth<br/>Writes MERIDIAN.OUT in scratch directory
    Model-->>Parser: MERIDIAN.OUT file on disk<br/>[Data: Column-exact ASCII (FORMAT 912)]

    %% 6. Parse and store forecast
    Note over Parser: Slices fixed column character spans (MRD-143)<br/>Constructs ForecastResult DTO
    Parser->>Store: INSERT INTO forecast and forecast_daily<br/>[Data: Parameterized SQL transaction]

    %% 7. Console requests forecast series
    Console->>API: HTTP GET /api/series?station=GUELPH&year=2025<br/>[Data: HTTP Request]
    API->>Store: Query daily series records<br/>[Data: JDBC SQL SELECT query]
    Store-->>API: Series rows<br/>[Data: JDBC ResultSet]
    API-->>Console: Daily series JSON payload<br/>[Data: application/json]

    %% 8. Presentation
    Note over Console: Populates #series table<br/>Renders DOM bar chart (#chart div.bar)
